# Lumiere Design System

## Brand
- Product: Lumiere Higher-Ed Pathways — Private Academic Operating System
- Aesthetic: Institutional premium. Harvard gravitas meets Linear clarity.

## Colors (Light Mode)
- Background: #FAFAF5 (warm ivory)
- Background Alt: #F3F1ED
- Card: #FFFFFF
- Foreground: #1A1A1A (near-black)
- Primary: #A41034 (deep crimson — all buttons, active states, accents)
- Primary hover: #C41842
- Muted: #8C8C8C
- Border: rgba(0,0,0,0.07)
- Success: #2D8B5F
- Warning: #B8860B
- Danger: #C0392B
- Info: #2E6B9E

## Colors (Dark Mode)
- Background: #0E1117
- Card: #1C2029
- Foreground: #E8E6E1
- Primary: #D44060

## Typography
- Display/Headings: Crimson Pro (serif) — font-display, font-serif
- Body/UI: Source Sans 3 (sans-serif) — font-sans
- Data/Numbers: IBM Plex Mono — font-mono
- Heading style: font-light tracking-tight, crimson accent on key words

## Spacing
- Border radius: 10px (cards), 12px (modals), 8px (buttons)
- Card padding: 20-24px
- Section gaps: 28px between sections

## Components
- Cards: border border-border/60, card-hover-glow on hover
- Buttons: h-9 default, h-12 hero CTAs
- Active sidebar: crimson pill indicator + icon tint
- Schedule items: colored dots (not border brackets)
- Dividers: gradient-divider (fade in/out)
- Tables: rounded border container, uppercase tracking headers

## Animation
- BlurFade for page entrance (staggered delays)
- NumberTicker for data values
- ShimmerButton for primary CTAs
- Particles for hero/sign-in backgrounds
- ScrollReveal with varied directions (up, left, right, scale)
- TextAnimate word-by-word for hero headlines
- Marquee for announcement ticker
- BorderBeam on sign-in card
